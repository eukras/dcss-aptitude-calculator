# DCSS 0.34 Aptitude Calculator

- Using an ODS spreadsheet
- take the species skill aptitudes in [Dungeon Crawl Stone Soup 0.34](https://crawl.develz.org/)
- and apply weightings based on a player's preferred playing style
- to select a species to play.
